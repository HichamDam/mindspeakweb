¿Qué es MindSpeak?

MindSpeak es una aplicación diseñada para ayudar a personas con TEA que tienen dificultades para expresar sus emociones. Nuestra plataforma ofrece una manera intuitiva y visual de comunicar sentimientos, permitiendo a los usuarios seleccionar entre diferentes emociones con varios niveles de intensidad y añadir una descripción de por qué se sienten así.

Además, la aplicación proporciona herramientas valiosas para supervisores y familiares, que pueden ver notificaciones cuando el usuario registra una emoción, consultar el historial emocional y visualizar gráficos de tendencias a lo largo del tiempo. También pueden asignar ejercicios y recursos personalizados para ayudar a gestionar las emociones.

Desarrollada por estudiantes del Ciclo Formativo de Grado Superior de Desarrollo de Aplicaciones Multiplataforma, MindSpeak nace del deseo de utilizar la tecnología para mejorar la calidad de vida de las personas con TEA, facilitando la comunicación emocional de una manera cómoda y segura.
