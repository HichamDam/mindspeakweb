Características Principales

MindSpeak ofrece una serie de funcionalidades diseñadas para mejorar la comunicación emocional

Selección de Emociones

Interfaz visual e intuitiva para seleccionar diferentes tipos de emociones con imágenes representativas y colores asociados.

  • 5 emociones básicas: Feliz, Triste, Enfadado, Miedo, Ansioso
  • Indicación de intensidad en escala 1-5
  • Diseño accesible y amigable

Historial Emocional

Registro cronológico de todas las emociones expresadas, con fecha, hora y descripción.

  • Visualización ordenada por fecha
  • Filtrado por tipo de emoción
  • Acceso a descripciones e imágenes

Sistema de Alertas

Notificaciones a supervisores y familiares cuando el usuario registra una nueva emoción.

  • Alertas en tiempo real
  • Gestión de múltiples usuarios
  • Acceso directo al historial

Análisis de Datos

Gráficos y estadísticas sobre las emociones registradas para analizar tendencias y patrones.

  • Distribución de emociones por semana
  • Evolución temporal de cada emoción
  • Identificación de patrones recurrentes

Ejercicios Personalizados

Recursos y actividades para ayudar a gestionar las emociones, personalizables por los supervisores.

  • Soporte de múltiples formatos (imagen, vídeo, audio)
  • Asignación individual o grupal
  • Organización por categorías

Privacidad y Seguridad

Protección de los datos personales y emocionales de los usuarios con medidas de seguridad avanzadas.

  • Autenticación segura
  • Control de acceso por roles
  • Cifrado de datos sensibles

Detalles Técnicos

Un vistazo a la tecnología detrás de MindSpeak

Tecnologías Utilizadas

  • Frontend: Kotlin con Jetpack Compose para la interfaz de usuario
  • Backend: Firebase para autenticación y base de datos en tiempo real
  • Almacenamiento: Supabase para imágenes y recursos multimedia
  • Diseño: Figma para el prototipado y diseño de interfaz

Arquitectura

MindSpeak utiliza una arquitectura en capas que separa la interfaz de usuario, la lógica de negocio y el acceso a datos. Esta estructura modular facilita el mantenimiento y la expansión de la aplicación.
