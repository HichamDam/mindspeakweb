Main Features

MindSpeak offers a range of functionalities designed to improve emotional communication

Emotion Selection

Visual and intuitive interface to select different types of emotions with representative images and associated colors.

  • 5 basic emotions: Happy, Sad, Angry, Afraid, Anxious
  • Intensity indication on a 1-5 scale
  • Accessible and user-friendly design

Emotional History

Chronological record of all expressed emotions, with date, time, and description.

  • Display ordered by date
  • Filtering by emotion type
  • Access to descriptions and images

Alert System

Notifications to supervisors and family members when the user records a new emotion.

  • Real-time alerts
  • Management of multiple users
  • Direct access to history

Data Analysis

Charts and statistics on recorded emotions to analyze trends and patterns.

  • Distribution of emotions by week
  • Temporal evolution of each emotion
  • Identification of recurring patterns

Customized Exercises

Resources and activities to help manage emotions, customizable by supervisors.

  • Support for multiple formats (image, video, audio)
  • Individual or group assignment
  • Organization by categories

Privacy and Security

Protection of users' personal and emotional data with advanced security measures.

  • Secure authentication
  • Role-based access control
  • Encryption of sensitive data

Technical Details

A look at the technology behind MindSpeak

Technologies Used

  • Frontend: Kotlin with Jetpack Compose for the user interface
  • Backend: Firebase for authentication and real-time database
  • Storage: Supabase for images and multimedia resources
  • Design: Figma for prototyping and interface design

Architecture

MindSpeak uses a layered architecture that separates the user interface, business logic, and data access. This modular structure facilitates maintenance and expansion of the application.

Code example: Emotion registration 
// Log in
suspend fun login(
    email: String,
    password: String,
    onSuccess: () -> Unit,
    onFailure: (String) -> Unit
) {
    try {
        // Authentication via Firebase Auth
        auth.signInWithEmailAndPassword(email, password).await()
        onSuccess()
    } catch (e: Exception) {
        onFailure(e.message ?: "Unknown error")
    }
}

// Get the role of the connected user
suspend fun getUserRole(): String? {
    try {
        val userId = auth.currentUser?.uid ?: return null
        val documentSnapshot = db.collection("Person").document(userId).get().await()
        
        if (documentSnapshot.exists()) {
            return documentSnapshot.getString("role")
        }
    } catch (e: Exception) {
        println("Error getting role: ${e.message}")
    }
    return null
}
